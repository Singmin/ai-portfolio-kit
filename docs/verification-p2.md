## 完成范围

- `setup`：交互填写公开资料、语言、主题、页面与首页模块，或从严格 JSON 生成唯一草稿；不自动覆盖用户配置。
- `setup:preview`：独立副本、loopback、无 Key 预览，不覆盖 3000 端口站点或复制环境文件/Git。
- `setup --apply`：在内存中加载实际内容模型、验证引用，再备份并原子写入固定配置文件；可恢复。
- `publish:check`：只读真实配置，输出字段级 error/warning、JSON、strict/preview 模式；不构建、发布或请求远程 URL。
- 三套完整标注示例、初始化/升级/版本/部署/排错文档；GitHub 模板标记已通过 API 验证为 true。
- Node 单机与静态两种构建。静态产物仅含页面/资源，浏览器使用同一评分函数检索授权原文，没有服务器 API 或付费模型。
- 配置覆盖层为 `src/config/customization.json`，原始 `version: 1` 默认保持现状；未填入真实个人资料，当前身份仍是明确示例、noindex。
