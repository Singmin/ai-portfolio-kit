## 授权边界与同步证据

单元/API 测试包含：

- 已发布但未授权的内容仍可阅读，不进入来源、建议或模拟模型请求。
- 职责/贡献范围直接来自项目字段；修改文字更新 revision、保留来源 ID。
- 撤销、删除、草稿、示例、停用页面或语言后，来源和相关建议消失；精选草稿不导致首页崩溃。
- 示例 profile 即使误设授权也不索引；真实 profile 才能产生技能/联系问题，贡献引用使用实际 open/closed 状态。
- 文章只抽取明确标记的段落；动态表达式、隐藏属性/容器、重复 ID、图片和非单段文本被拒绝，授权但未标记时指出具体字段。
- 未标记正文、私有字段、根目录私人测试文件、环境变量和检索内部属性不进入模拟 provider 请求；草稿即使误设授权也不解析。
- 文本更新、撤销、无效编辑后的清空与修复恢复；原有模型恶意输出、未知来源、额外字段、失败及预算回退测试继续通过。

完整隔离结果：`.cache/evidence-fixtures-1793034903769/`，端口 3141–3143，测试完成后关闭场景服务器。所有身份、联系和贡献内容为明确的本地测试资料，未发布，也不覆盖用户站点配置。

1. **authorized**：实际生产 API 引用文本与正文 DOM 一致，浏览器定位到 `#evidence-scope`；职责和邮件来自获准字段。未标记正文、私有测试文件、未授权项目均得不到来源；草稿详情 404，未授权的已发布项目仍为 200。
2. **development**：修改标记正文后，无手动 sync，页面与 API 自动更新；来源 ID 不变、revision 变化。修改 JSON 撤销授权后，API 自动移除该来源。
3. **revoked**：所有授权关闭后，来源与建议为空，查询按钮禁用；普通公开页面仍为 200，也没有旧手工来源回退。
