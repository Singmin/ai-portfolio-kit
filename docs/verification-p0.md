- 统一站点品牌、模板信息、默认语言、页脚、页面开关、导航顺序及首页模块配置，并在启动/构建时校验。

- Kit 实际仓库链接已配置；不再以缺失链接推断项目仅在本地。四张真实截图归属于 Kit 项目配置，并已刷新为本轮界面。
- 问答保留显式白名单和原文摘录，按实际 slug、贡献内容和页面开关生成引用，忽略空白摘录。没有自动扫描 MDX、其他仓库或私人文件。
- 新增配置迁移指南和隔离示例验证脚本，保留了此前未提交的 README、AGENTS 与路线文档内容。

## 视觉复核

保持原有森林绿与浅绿、编辑式排版和本地字体。布局顺序为身份主视觉、配置化作品与媒体、文章列表、关于、资料助手和页脚；经历、贡献及联系模块按真实内容显示。

自评：设计 7.5、可用性 8、创意 7、内容 7，加权 7.5。没有发现图片损坏、按钮与标题遮挡或手机横向溢出。可选项目字段在详情页保持清楚的阅读层级；图片缺失时的纯文本案例通过组件与真实 HTTP 验证。

设计检查的非阻断提示：两种语言均没有视频；软件以实际界面截图和细微动态展示，不添加无关素材。英文另有一处“行长”提示，来自全宽示例状态说明；常规阅读正文保留约 70ch 的宽度限制。当前没有通过隐藏内容或放宽检查规则来跳过失败项。

截图及机器报告在本地 `.taste-skill/p0-en`、`.taste-skill/p0-zh`、`.taste-skill/p0-projects`，未加入 Git。四张随项目分发的界面截图仍保存在 `public/previews`。

## 保留的边界

- 没有配置或使用真实 API Key，外部模型边界仍以模拟响应测试；离线问答通过真实浏览器验证。
- 未改变请求/模型预算、超时和单机限流存储实现。多机/serverless 共享限流仍属于后续工作。
- 没有新增依赖。没有开发多主题、拖拽、CMS、单语言回退、自动 MDX 发现或完整内容索引。
- 当前项目的个人身份仍明确标注为示例，工作/教育/外部社区贡献没有伪造记录。
- 构建出现 Windows MDX loader 缓存依赖分析提示，Vitest 保留未来原生配置加载器提示；均未导致本轮检查失败。没有修改依赖或屏蔽提示。
- 本轮没有创建 Git 提交、推送 GitHub、运行远程 CI 或发布线上站点；此前历史验证不作为本轮结果。
- 验收服务和隔离服务已停止；用户原有的 3000 预览服务保持运行。
