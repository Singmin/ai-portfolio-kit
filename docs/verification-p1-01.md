# P1-01 实现与本地验证记录

日期：2026-10-26。范围：路线中的三套视觉预设及其配置、阅读切换、响应式布局、键盘、打印和动态降级。P1-02 / P1-03 / P2 没有在本轮宣称完成。

## 实际改动

- 增加编辑式、工程式和履历式。编辑式延续森林绿与大字叙事；工程式使用技术方向、项目决策与截图的双栏结构；履历式限制阅读宽度、缩短间距、改为紧凑列表与四列小图，手机使用两列小图。
- 在页眉下方提供双语“阅读方式”按钮，当前选择有 `aria-pressed` 状态。跨页面、语言切换与刷新保存浏览器选择；非法存储值回退默认，无法写入存储时仍可在当前页面切换。
- 在 `site.appearance` 中配置服务器默认预设、是否允许切换，以及配色、字体、密度、媒体比例与动态开关。锁定预设时忽略旧的浏览器选择；未提供配置的旧数据在校验时补上编辑式默认值。
- 旧全局样式整理为 tokens、components、presets、accessibility 四层，由同一个布局入口按顺序导入；修正了浅色主题下的文本、表单、按钮和强调区域对比色。
- 所有预设共用公开内容、模块顺序、页面开关与证据链接。工程式展开已有的技能与项目决策；无媒体案例保留文字阅读布局。没有新增虚构身份或成果。
- 系统减少动态效果或 `motion: 'reduced'` 均关闭动画和过渡；三种屏幕预设共享白底黑字的简历打印规则。
- 新增 `tests/appearance.test.tsx`、`e2e/appearance.spec.ts`；隔离配置脚本补充锁定工程式/履历式的服务器 HTML 验证。用法与迁移见 [外观配置说明](appearance-p1.md)。

## 视觉复核与仍存提示

方向为 Type and nothing else，seed `1738362744`，无重抽。编辑式保留既有字体与配色；工程式和履历式按本轮明确需求提供不同构图。现有导航和首页模块顺序契约优先于方向表中的通用建议。

设计想法：同一份公开证据成为三种阅读结构。可实际操作的核心是切换阅读方式，而不是给相同布局替换颜色。

ROUND 1

- Seen in one second：编辑式的大字、工程式的决策对照、履历式的紧凑双栏。
- Idea：一份公开内容，三种阅读优先级。
- Live thing：切换阅读方式并保持事实、项目链接与模块配置。
- Layout words by section：editorial = statement / gallery / list / colour field；engineering = split / decisions with media / offset list / statement；resume = compact split / record / list / close。
- Scores：design 7.5 · usability 7 · creativity 7 · content 7 → overall 7.2。
- Caps applied：没有虚构证明材料；示例身份限制内容的个人辨识度。
- Top three problems：手机版履历式首屏不够紧凑；工程式和履历式技术栈未沿摘要左侧对齐；无脚本说明需要可见回退。以上已修正。

ROUND 2 / 最终复核

- Seen in one second：三套排版差异清楚，履历式手机首屏已缩短。
- Idea / Live thing：保持上述结构，配置与切换均实际工作。
- Layout words by section：沿用上述三套构图；中文标题进一步按自然标点断行。
- Scores：design 7.5 · usability 8 · creativity 7 · content 7 → overall 7.5。评分是本次自评，不是外部评审。
- Caps applied：个人资料仍为示例，内容无法表现真实个人特色。
- Remaining issues：作品仍只有一个模板项目；工程式详情侧栏资料较少；现有四张项目图片是原有 Kit 界面截图，没有另造视频或外部摄影来填充页面。

检查器保留的 WARN：所有预设均没有视频；英文编辑式与履历式有一处长行提示。前者因当前软件项目使用四张真实界面截图，无相关视频素材；后者来自全宽示例身份说明，普通正文已有阅读宽度限制。没有隐藏这些内容或修改规则以消除提示。
