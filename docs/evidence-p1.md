# 公开来源与 AI 授权（P1-03）

页面公开与 AI 索引授权相互独立。默认不索引；离线检索和可选模型共用获准来源。没有 Key 时仍可阅读页面和检索，模型仅筛选来源编号，服务器返回原文，不生成个人经历或自由推断。

## 配置授权

| 内容 | 公开发布条件 | 加入检索还需要 |
| --- | --- | --- |
| 个人简介/技能/联系 | `resume` 页面启用、公开 profile 配置 | `profile.aiIndex: true` 且 `isExample: false` |
| 项目 | `publication: 'published'`、projects 页面启用 | 项目条目 `aiIndex: true` |
| 贡献 | `publication: 'published'`、contributions 页面启用 | 贡献条目 `aiIndex: true` |
| 文章 | `status: 'published'`、blog 页面启用且存在该语言正文 | JSON 中 `aiIndex: true`，以及正文中的显式段落标记 |

项目/贡献省略 `publication` 时沿用原来已公开的行为；省略 `aiIndex` 时始终不索引。`draft` 不展示，`example` 仅在模板预览中展示且始终不索引。个人示例身份即使误设 `aiIndex: true` 也不索引。字段类型保留现有中英文对象合同。

当前仓库显式授权了真实的模板项目和两篇模板文档；个人资料仍为示例且未授权，贡献记录仍为空。复制或替换条目后应重新审核 `aiIndex`，不要把模板的授权照搬到未核验的个人内容。

授权是条目级别的：profile 提供 bio、技能列表、邮件与 GitHub；项目提供技术栈、简介、问题、决策、结果、角色与贡献范围；贡献提供实际状态和公开摘要。没有设置的职责/联系方式不会生成来源或建议问题。其他任意字段、环境变量、私人文件和简历不会被扫描；该版本不自动索引个人经历条目、教育记录、项目指标或附件。

## 文章：只维护一次正文

在文章 JSON 中设置 `aiIndex: true`，并在每个获准语言正文中加入：

```mdx
<PublicExcerpt id="architecture-decision">

这里写实际会展示给读者的原文段落，可以含 **强调**、`行内代码` 和普通链接。

</PublicExcerpt>
```

这段内容仍是正常正文。全局 MDX 组件为它生成 `#evidence-architecture-decision` 锚点；登记脚本使用 MDX 解析器读取同一段静态文本，生成来源，无需在问答文件里再复制摘录。解析只处理明确登记的本地文章，不 import/evaluate MDX，不读取正文导入的文件，也不访问网络。

- 每个语言正文最多 12 个标记，每个标记含 1 个、1–2000 字符的静态段落。
- ID 使用不重复的字母数字/短横线 slug；修改段落内容时保留 ID。改变 ID 会改变来源和锚点，可能影响既有引用。
- 支持文本、强调、行内代码、换行与链接文字；不抽取图片、代码块、动态表达式或组件计算结果。
- 标记必须在正文顶层，只有一个字面量 `id` 属性；禁止 `hidden`、动态属性、嵌套隐藏容器和多个段落，避免摘录与可见原文不一致。
- 已授权、已发布的正文没有标记，或包含无效标记时，会给出文件/字段错误；草稿即使误设授权也不解析为来源。
- 仅有 `aiIndex: true` 不会自动读取整个正文；未标记的段落不会进入模型请求。

MDX 仍是可信可执行页面代码，必须经维护者审核。抽取约束不是不可信上传内容的沙箱。

## 稳定 ID、更新和撤销

来源 ID 从内容身份和字段生成，例如 `project:my-project:role`、`post:my-note:architecture-decision`、`profile:contact`。贡献使用其公开 URL 的编码生成 ID，同一条 PR 的状态更新不改变来源身份。每个来源还有由语言、标题、链接和原文计算的 16 位 SHA-256 修订标识，文本变化会更新它。

项目等配置字段直接供页面和来源读取；文章登记脚本生成正文摘录。开发服务器监视明确的 `src/content/posts/` 目录，正文或授权 JSON 修改后自动更新；若编辑暂时不合法，会清空文章登记/导入，防止保留旧的获准摘录，修复后自动恢复。其他类别的合法来源仍按自身授权工作。

生产构建会重新生成来源。**生产撤销、删除或修改内容后，必须重新构建并重启/部署**；仅修改磁盘上的源文件不会改写已经运行的构建产物。没有定时爬取、外部向量库或自动训练。

撤销 `aiIndex` 保留公开页面、搜索和 sitemap，但移除来源及相应建议；改成草稿会同时移除公开内容。关闭页面或语言也会取消相应来源资格。缺少翻译时不会把另一语言正文与当前语言摘录混合。

## 访客界面和模型边界

建议问题从当前获准的技能、项目职责、公开贡献、联系方式和文章生成，最多 4 个；不存在的类别不显示。当前语言完全没有来源时显示说明并禁用查询按钮，API 也返回未知答案，不调用模型。

关键词检索最多选择 3 条候选。模型仅接收问题与这些已授权的原文引用，无法访问整个配置对象、私有文件或环境变量；返回编号必须属于候选集合，额外生成字段、未知编号、失败、超时或预算不足均回退到原文。已保留 8 秒模型超时、输出上限、请求校验、限流和无 Key 降级。长配置字段最多引用原文前 2000 字符，文章标记则在构建时检查长度，不以生成文字补齐。

## 迁移与验证

删除了原来的 `approvedArticles` 手工复制摘录。为确实可以进入检索的项目、贡献或真实 profile 显式加 `aiIndex: true`；文章再补上上述标记。新内容省略授权时继续正常公开，但不会自动发送给模型。

运行 `npm run content:sync` 可手动生成，正常开发和构建会自动处理。相关检查：`npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`、`npm run test:evidence-fixtures`。`@mdx-js/mdx@3.1.1` 从既有传递依赖提升为锁定的直接依赖，没有升级解析器版本。
