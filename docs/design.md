# Design notes

Subject inventory: bilingual routes; one real local project; editable public profile; source excerpts; honest empty contribution record; trusted MDX; independent Git history; the same page as a personal portfolio and an open-source starter.

Argument: show what the portfolio is → inspect the actual kit → read engineering decisions → understand the public profile boundary → ask the allowlisted evidence.

Idea: on this page, the kit's public evidence becomes an editable field notebook. The live interaction is asking a question and following its exact public source. This is usable through public source pages without JavaScript.

Direction: design-taste-frontend, `type-only-statement`, forest and lime, Imbue / Albert Sans, color by chapter. One oversized typographic statement introduces the work; real kit screenshots appear below it. No invented imagery or external project screenshots are used. The public profile is clearly labelled as sample content.

The farm photograph suggestions in the direction sheet were not used: they would not describe this software. The four images are screenshots of this project's resume, projects, blog, and contributions pages. All are generated from its running UI. Fonts are hosted locally with their OFL licenses, avoiding build-time font network dependencies. Chinese uses system CJK faces with matching proportions. Section fields change at natural edges. Motion uses transform and opacity; reduced motion keeps content visible.

Copy: English hero “Work, with evidence.” (20 characters), Chinese hero “用作品，讲清能力。” (9 characters). Both fit in two lines at phone widths. Inner pages use shorter titles and full-width content before the reading column.
