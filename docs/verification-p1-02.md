## 实现与迁移

- 每篇 `posts/<slug>.json` 登记元数据和已有翻译，正文统一为 `<slug>.<locale>.mdx`；共享 schema 校验后生成静态元数据和可枚举的延迟导入。构建和开发启动自动同步，开发运行中的登记变更使用 `content:sync`。
- `enabledLocales`、`defaultLocale`、`missingTranslation` 控制单语言、缺失翻译隐藏或默认语言原文回退。首页、列表/搜索、导航、语言切换、文章 metadata、sitemap 和来源过滤使用同一份有效内容。
- 草稿从生成的公开元数据与 MDX 导入中排除；示例仅在模板预览展示并标注，详情 noindex；只有已发布且已有人工白名单授权的文章才保留问答来源资格。
- 构建检查登记、日期、slug、翻译字段与正文、局部媒体文件、静态内部引用、URL 格式和语言约束，错误定位到文件或字段。明确的校验范围和原字段迁移见 [配置指南](content-p1.md)。
- 文章 metadata 保留上层模板预览的 noindex。单篇搜索结果使用 `1 note`，多篇和空结果仍正确显示。

## 隔离场景与截图

本轮结果目录：`.cache/content-fixtures-1793032686382/`。三个副本共享只读依赖，具有独立配置、构建和端口（3121–3123），验证结束后关闭场景服务器；不覆盖当前站点配置。测试资料仅为本地场景，不是个人经历或已发布站点。

1. **en-only**：只生成/允许英文路由，根路径转到 `/en`；中文首页、文章、项目与问答页面 404，API 拒绝中文，header 无语言切换，sitemap 无中文项或 alternates。
2. **zh-only**：同样验证中文与停用英文的对应行为，根路径转到 `/zh`。
3. **partial**：一篇仅英文、一篇仅中文，默认英文并开启原文回退；验证语言切换回到可访问的文章列表、中文列表链接英文原文、缺失默认正文返回 404、metadata canonical 与 alternates 不虚构翻译、草稿无法搜索。

每个副本都加入正文为**非法 MDX**的草稿。三个生产构建均通过，证明草稿代码未被导入编译；草稿和示例详情返回 404，标题不出现在公开搜索或 sitemap。问答来源另有单元测试覆盖草稿、示例、停用语言、缺失翻译与人工白名单边界。

每个场景保存了 1440px 和 390px 截图；人工查看英文桌面、中文手机及 partial 桌面/手机。阅读列表和页眉无裁切或横向溢出。截图检查发现单篇时使用 `1 notes`，随后改为 `1 note` 并由最终生产构建的桌面/手机搜索测试复验；该目录截图保留修正前的计数文案。

Next.js 的按需页面可能使用 HTTP 跳转或流式 meta 跳转，隔离测试以浏览器实际到达默认语言原文为准，不把首个响应必须有 Location 头作为功能条件。
